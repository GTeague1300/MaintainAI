# MaintainAI

AI-assisted equipment maintenance management system.

## Project overview

MaintainAI is a maintenance management application designed
to help organisations report equipment faults, manage work
orders and monitor maintenance activity.

AI-assisted functionality will classify reported faults,
recommend priorities and suggest troubleshooting actions.

## Technology stack

- Python
- Flask
- React
- PostgreSQL (Neon)
- MongoDB Atlas
- Git and GitHub
